# Network Lab Files

This repository contains network lab exercises and configurations for CCNA studies. It includes various practical setups and simulations to help reinforce networking concepts.

## Contents

- **Lab 1: Basic Router Configuration**  
  Description: A step-by-step guide for configuring basic router settings such as hostname, interfaces, and routing.

- **Lab 2: VLAN Configuration**  
  Description: A guide to setting up Virtual Local Area Networks (VLANs), configuring trunking, and verifying connectivity.

- **Lab 3: Routing Protocols**  
  Description: Exercises on implementing static routes, RIP, and OSPF on routers and switches.

- **Lab 4: Access Control Lists (ACLs)**  
  Description: Implementation of standard and extended ACLs to control network traffic.

- **Lab 5: NAT and PAT**  
  Description: Configuration of Network Address Translation (NAT) and Port Address Translation (PAT) for internal network access to the internet.

## Requirements

To run these labs, you will need:
- Cisco Packet Tracer or GNS3 (for simulation)
- A basic understanding of networking concepts (IP addressing, routing protocols, etc.)
